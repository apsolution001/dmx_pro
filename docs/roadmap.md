# DMX Pro — Roadmap

Follows spec §13, extended with Music Show. Each phase ends with tests green and a demo-able build.

| Phase | Name                 | Contents                                                                 | Status  |
|-------|----------------------|--------------------------------------------------------------------------|---------|
| 0     | Knowledge & setup    | Research docs, spec in Markdown, AI agent rules/standards                | ✅ Done |
| 1     | Foundation           | Solution, DI, Fluent shell + navigation, project model, save/open, profile model + editor, built-in profiles, QLC+ `.qxf` import | ⏳ In progress |
| 2     | Fixture patching     | Fixture list, add/edit form, address calculator, overlap validation, groups | ⬜ |
| 3     | Scene Creator        | Profile-driven controls, color picker, RGBW policy, fades, save/duplicate, stage preview | ⬜ |
| 4     | Engine & Functions   | Engine tick, HTP/LTP merge, chaser, sequence, color cycle, fade, pulse, flash, strobe; copy/paste | ⬜ |
| 5     | Virtual Console      | Widgets, pages, drag/resize/snap, operator lock, keyboard mapping        | ⬜ |
| 6     | Test & Preview       | Raw channel test, RGB(W) tests, DMX monitor, footprint view, diagnostics | ⬜ |
| 7     | Hardware output      | Virtual output, Art-Net, sACN, Enttec USB Pro, Open DMX (FTDI); status & errors | ⬜ |
| 8     | Show Timeline        | Multi-track timeline, audio tracks + waveform, place/create functions in time ranges, beat markers & snapping, synced playback; later: auto-fill helpers, live sound-to-light | ⬜ |
| 9     | Reliability & polish | Autosave/recovery, undo/redo everywhere, first-run wizard, installer (MSIX/Inno) | ⬜ |
